# Off-market model: report-ready draft

We compared five prespecified candidates using the official expanding-window evaluation for December 2025 through May 2026 (10,069 homes). Each monthly model was fitted only on transactions completed before the first day of that month. Our selected candidate, `history_text_boost`, used 70 features. We compared the official gradient-boosted feature model, corrected Member 1 property/location features, additions of trailing sales statistics and fixed description keywords, and an ExtraTrees alternative. The enhanced boosting candidates shared fixed hyperparameters. We modeled log sold price and exponentiated predictions. We did not use list price, days on market, third-party AVMs or the current home's actual sale date as predictors. Categories and any imputation were learned separately within each training fold; historical features used only that fold's sales strictly before the query home's listing date, excluding same-day and self transactions.

The selected model achieved pooled validation MdAPE of **9.474%** and MAPE of **12.107%**, versus **20.843%** and **27.430%** for the supplied nearest-sales baseline. This is a MdAPE reduction of **11.369 percentage points (54.5% relative)**. Median signed percentage error was **+0.065%**. The 90th percentile of absolute percentage error was **24.803%**, indicating that point estimates can still have substantial individual errors. See the accompanying monthly, property-type and price-band diagnostics; price bands are diagnostic only and are never inputs.

Error was larger for homes above CAD 2 million (MdAPE 15.183%, median signed error -10.940%) than for CAD 600,000-1 million homes (MdAPE 8.830%). Co-Op apartments had MdAPE 14.592% but only 48 observations. Historical statistics alone did not improve the enhanced property model (9.926% to 10.044%); adding fixed text indicators to the history candidate reduced error to 9.474%. We did not separately test text without history, so we cannot attribute the final gain to history itself.

We selected the lowest pooled validation MdAPE, with MAPE as a tie-breaker. These same months were used for model comparison, so this is selection-set performance, not an independent final test; hidden-test performance may deteriorate. The supplied baseline predictions were audited and rescored rather than retrained. The monthly protocol follows the competition runner and is not a full listing-day backtest for long-running listings. Small property subgroups and shared monthly market shocks limit precision. We do not claim calibrated prediction intervals or that validation accuracy guarantees an individual home's value. No external data or hidden test outcomes were used.
