## Member 1代码修正与整合方式

- member1_features.py保留了队友的实现并修复两处问题：面积解析改用去逗号后的文本；历史统计累加与保存放回正确的分组循环。桌面源文件未修改。
- 新数值特征包含原变量、对数面积、面积区间/缺失标记、对数地块、季节sin/cos、日期缺失、未知房型、对数挂牌价等，共30项。
- 加上现有的房屋风格、municipality、community原生类别编码，基础共33项。保留Member 1清理结果，不再用原始数值覆盖。
- 没有同时启用FeatureBuilder的一热编码，避免再用另一组编码重复加入区域。
- 没有替换团队公用features.py；Member 1特征隔离在单独模块，不影响Off-market或之前实验的可复现性。

## 两组历史特征不同在哪里

- 原方案：过去三个日历月的成交挂牌比中位数和样本数，分组至少20笔，按社区/房型向较大范围回退。训练行使用其成交月开始前的历史；预测使用fit时快照。这是比赛月度协议，不代表挂牌当日预测。
- Member 1方案：以每套房挂牌日为截止，90/365天窗口，计算全市场、房型、municipality＋社区＋房型三个层级的成交数量、成交均价、有效面积数量、平均每平方英尺价格，共24项。
- 每个验证折只fit训练成交；每条记录按挂牌日截取严格更早的成交，排除同日、未来和自己的ID。少于5笔时均价保留NaN。发布日期延迟采用默认0天。
- 组合方案包含两组历史，不把它们视作同一个指标。所有训练特征均不使用当前房屋的未知成交答案。

## 使用哪些文件

- source/models.py：本轮选中模型的入口；合并时只处理List-aware分支。
- source/list_aware_member1_model.py：Member 1特征与比例树的整合。
- source/member1_features.py：修正后的队友特征代码。
- source/list_aware_feature_models.py：原历史成交挂牌比实现，组合方案会依赖它。
- source/experiment_list_aware_member1.py：重跑本轮五组实验。
- source/tests/test_member1_integration.py：修复、历史窗口、排除未来、类别和禁止字段检查。
- results/validation_predictions.csv：给Member 4逐条分析；summary/monthly/by_property_type/by_price为成绩表。
- results/submission_list_aware.csv：选中方案训练全部历史后的4,064条测试预测，格式检查通过。
- reference/features.original.py：Member 1原版备份；不能直接当作修复版本使用。

## 复现

在source内用Python 3.10+安装requirements.txt，设置OMP_NUM_THREADS=2，再运行：

```bash
python experiment_list_aware_member1.py
```

初次需要联网下载数据。本机已有缓存，训练和验证不需要新增外部数据。
